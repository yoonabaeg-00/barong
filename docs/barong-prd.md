## 1. 배경 및 문제 정의

업무용 캘린더와 알림 도구는 대부분 기능적이지만, 하루를 함께 보내는 감정적 동반감은 부족하다. 사용자는 회의 알림, 출근/퇴근 루틴, 중간중간의 응원 같은 작은 업무 보조를 원하지만, 기존 생산성 앱은 딱딱하고 쉽게 피로감을 준다.

바롱이는 사용자의 노트북에 사는 업무 반려펫이다. 사용자가 일을 시작하면 츄르를 먹고 하루를 함께 시작하고, Google Calendar 회의 10분 전에 귀엽게 알려주며, 퇴근할 때 밥을 먹고 하루를 마무리한다. 핵심은 단순한 알림 앱이 아니라 “내가 일하는 동안 작은 친구가 같이 출근한다”는 감정이다.

추가로, 바롱이를 배포하기 위한 다운로드 랜딩페이지가 필요하다. 랜딩페이지는 제품 컨셉을 보여주고, 앱 다운로드와 캘린더 권한에 대한 신뢰를 제공해야 한다.

## 3. 사용자 및 페르소나

**주요 사용자:**
- 혼자 일하거나 공부하는 맥북 사용자
- 캘린더 기반으로 회의가 많은 직장인
- 귀여운 데스크톱 펫, 다마고치, 픽셀 캐릭터를 좋아하는 사용자
- 딱딱한 업무 툴보다 감정이 있는 작은 도우미를 선호하는 사용자

**사용자 스토리:**

| 사용자 | 원하는 것 | 이유 |
|--------|-----------|------|
| 맥북으로 일하는 사용자 | 노트북을 켜면 바롱이가 반겨주기를 원한다 | 하루 시작을 귀엽게 느끼고 싶다 |
| 회의가 많은 사용자 | 회의 10분 전에 회의명/장소/링크를 보고 싶다 | 캘린더를 계속 확인하지 않아도 되고 싶다 |
| 루틴이 필요한 사용자 | 츄르주기/밥주기로 출근과 퇴근을 체크하고 싶다 | 업무 시작과 종료를 의식적으로 구분하고 싶다 |
| 캐릭터를 좋아하는 사용자 | 바롱이와 함께한 기간을 보고 싶다 | 반려펫처럼 관계가 쌓이는 느낌을 받고 싶다 |

## 4. 제품 컨셉

**제품명:** 바롱이  
**컨셉명:** 바롱이 아일랜드  
**한 줄 설명:** 맥북에 사는 아비시니안 픽셀 고양이 바롱이가 누나의 출근, 회의, 퇴근을 챙겨주는 업무 반려펫.

**바롱이 캐릭터:**
- 아비시니안 픽셀 고양이
- 사용자를 `누나`라고 부름
- 다마고치처럼 돌봄 욕구가 있음
- 업무를 도와주려고 하지만 말투는 장난스럽고 애교 있음
- 츄르, 밥, 놀기, 졸림 같은 펫 욕구를 자주 표현함

**말투 예시:**
- `누나 왔어? 바롱이 기다렸어`
- `누나 열심히 해서 츄르 사줘~~`
- `누나 집중 안 하지!!`
- `누나 회의 10분 남았어!`
- `링크도 찾았어. 바롱이 똑똑하지?`
- `누나 이제 밥 줄 시간이야`

## 8. 핵심 UX 흐름

### 8.1 첫 실행

1. 사용자가 앱을 실행한다.
2. 바롱이가 노치/상단에서 빼꼼 나온다.
3. 바롱이가 말한다: `누나 왔어? 바롱이 기다렸어`
4. 바롱이가 Google Calendar 연결을 요청한다.
5. 사용자는 `캘린더 연결하기` 또는 `나중에`를 선택한다.
6. 캘린더 연결 후 또는 나중에 선택 후 `츄르주기` 화면으로 진입한다.

### 8.2 출근 체크

1. 사용자가 `츄르주기`를 누른다.
2. 바롱이가 츄르 먹기 모션을 보여준다.
3. 앱은 오늘 체크인 시간을 저장한다.
4. 바롱이가 말한다: `츄르 냠! 출근 완료다 누나`
5. Google Calendar가 연결되어 있다면 오늘의 다음 회의를 확인한다.

### 8.3 Google Calendar 연결

1. 첫 실행 온보딩에서 바롱이가 말한다: `누나 회의 알려주려면 캘린더 연결해야 돼`
2. 사용자가 `연결하기`를 누른다.
3. Google OAuth 창이 열린다.
4. 사용자가 캘린더 읽기 권한을 승인한다.
5. 앱은 토큰을 안전하게 저장한다.
6. 앱은 오늘 일정과 다음 일정을 가져온다.
7. 바롱이가 말한다: `좋아! 이제 회의는 바롱이가 봐줄게`

### 8.4 회의 10분 전 알림

1. 앱이 다음 회의 시작 10분 전을 감지한다.
2. 바롱이가 귀 쫑긋 모션을 보여준다.
3. 다이나믹 아일랜드 패널이 확장된다.
4. 패널에 다음 정보를 표시한다.

```text
누나 회의 10분 남았어!
14:00 주간 회의
회의실: 3F Lounge
```

5. 사용자는 `캘린더 열기`, `자세히`, `닫기` 중 하나를 선택한다.

### 8.5 퇴근 체크

1. 사용자가 바롱이를 클릭해 퇴근 메뉴를 연다.
2. 바롱이가 말한다: `누나 이제 밥 줄 시간이야`
3. 사용자가 `밥주기`를 누른다.
4. 바롱이가 밥 먹기 모션을 보여준다.
5. 앱은 체크아웃 시간을 저장한다.
6. 하루 요약을 보여준다.

```text
오늘 누나랑 같이 있던 시간: 8시간 12분
회의 알림: 4개
바롱이랑 산 지: 7일째
```

## 11. 기술 고려사항

### 앱 형태

MVP는 macOS 전용 네이티브 데스크톱 앱으로 구현한다. Windows는 이번 범위에서 제외한다.

| 후보 | 장점 | 단점 |
|------|------|------|
| SwiftUI + AppKit NSPanel | Notchi처럼 노치/메뉴바에 붙은 네이티브 느낌 구현 가능, 앱이 가벼움 | Electron보다 초기 구현 난이도가 높음 |
| Electron + React | 웹 기술로 빠르게 프로토타입 가능 | 노치에 침투한 느낌이 약하고 그냥 떠 있는 창처럼 보임 |

첫 구현 기술은 **SwiftUI + AppKit NSPanel**로 확정한다. 목표는 Notchi처럼 시스템 노치/메뉴바 영역에 자연스럽게 붙어 있다가 클릭 시 확장되는 경험이다. Electron 구현은 랜딩/초기 프로토타입 참고용으로만 둔다.

### Google Calendar

- Google Cloud 프로젝트 생성 필요
- Calendar API 활성화 필요
- OAuth consent screen 설정 필요
- Desktop app OAuth client 생성 필요
- 읽기 전용 캘린더 권한으로 시작
- 앱 설치 후 첫 실행 온보딩에서 계정 연결을 요청
- 개발/구현 과정에서는 개발자 Google 계정으로 먼저 연결해 동작 검증
- 토큰은 macOS Keychain 또는 안전 저장소에 저장
- 각 사용자는 본인의 Google 계정으로 직접 Calendar를 연결한다
- 앱은 연결된 계정의 캘린더만 읽는다
- 캘린더 일정 데이터는 서버에 저장하지 않고 로컬에서만 처리한다

참고 문서:
- [Google Calendar API authorization scopes](https://developers.google.com/workspace/calendar/api/auth)
- [OAuth 2.0 for Desktop Apps](https://developers.google.com/identity/protocols/oauth2/native-app)
- [Calendar Events list](https://developers.google.com/workspace/calendar/api/v3/reference/events/list)

### 바롱이 UI

- 기본 위치는 MacBook 상단 중앙 노치/메뉴바 영역에 붙은 네이티브 floating panel
- 기본 상태는 노치에 붙은 작은 검은 캡슐과 바롱이만 표시한다
- 사용자가 노치/바롱이 캡슐을 클릭하면 Notchi처럼 아래로 바롱이 아일랜드 패널이 확장된다
- 노치 없는 맥은 이번 MVP의 주요 지원 대상이 아니며, 필요 시 상단 중앙 캡슐 fallback으로 처리한다
- UI는 일반 앱 창처럼 보이면 안 되며, 메뉴바/노치에 붙은 시스템 companion처럼 보여야 한다
- 알림 상태에서는 자동으로 패널이 확장될 수 있다

### 랜딩페이지

- Vite/React 또는 정적 HTML로 구현 가능
- 다운로드 버튼은 실제 macOS 설치 파일을 제공
- macOS 전용 다운로드임을 명확히 표시하고 Windows는 현재 지원하지 않음을 안내
- 캘린더 권한을 왜 요청하는지 명확히 설명해야 함
- 개인정보/권한 안내 섹션 필수
